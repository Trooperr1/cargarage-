One-time setup (free)

  1. Go to app.netlify.com and create a free account (“Sign up”, e.g. with your e-mail).
  2. On this computer, open the website folder once: click Build website on the overview, then Download website as ZIP and unzip it.
  3. In Netlify click Add new site → Deploy manually and drag the unzipped folder onto the page. Your site gets an address like kurd-garage.netlify.app.
  4. In Netlify open Site configuration and copy the Site ID (also called Project ID). Paste it below.
  5. Click your round profile picture → User settings → Applications → Personal access tokens → New access token. Name it “Kurd Garage”, copy it and paste it below.
