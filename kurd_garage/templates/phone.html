How it works

  1. The phone must be in the same Wi-Fi as this computer.
  2. This computer must be on and the black window open.
  3. The first time, Windows asks “Allow access?” → tick Private networks → Allow access.
  4. If the phone can't connect: in Windows open Settings → Network → your Wi-Fi → set it to Private network.
  5. Log in on the phone with your normal username and password.

Away from the garage (mobile data, at home) this does not work. That needs an extra tool — ask if you want it.
